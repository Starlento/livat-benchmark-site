03 / HTTP INTERFACE

通过接口，让系统作出选择。

harness 在自己的进程中运行。
所有请求携带本题 Bearer token。

请求能力
GET /metadata读取全部七路相机、内外参、车辆几何与运动约束
GET /state查询当前生命周期、执行请求、sim_frame、action_seq 和预算
GET /observation读取最新完整观测、局部匿名占用与当前认证导航路径
GET /snapshot?observation_id=…一次下载固定观测、清单和对应同帧 PNG；省略 ID 取最新
GET /images/…读取已发布的原始 RGB；历史图片在本题 HTTP 服务期内可读
GET /requests/<request_id>查询动作回执，超时或断线后恢复同一个请求
GET /result读取固定终态公开结果，重复读取不重新评分
POST /move沿当前 path_id 执行自选弧长 distance_m，返回动作回执
POST /wait原地等待 1–10 秒，回执引用完成后的观测
POST /cameras选择相机子集或全部关闭；设备描述始终完整
POST /propose以四个有序角点登记匿名车位候选，ID 位于回执结果中
POST /costs报告累计模型请求与 token 成本
POST /submit提交最终选择，结束本题；从回执的业务结果读取评分
POST /acknowledge保存终态结果后显式确认，提前关闭 HTTP 服务

观察后，使用新的路径能力

每次新观测发布后，旧路径与候选失效，历史图片和快照仍可读取。移动距离至少 0.2 米，且不超过当前路径上限；前进或倒车由路径方向决定。

沿途观察，需要主动分段

一次移动只生成终点观测，不提供沿途图像。每段完成后用 snapshot(receipt.output_observation_id) 获取观测和图片，再用新路径决策。预算中断时需核对实际距离与结果，避免把旧观测当作终点图。

恢复执行，保留原请求身份

move、wait、cameras、propose、costs、submit 均携带 request_id。超时后用 receipt() 或 wait_for() 查询；相同 ID 与内容不会重复执行，不同内容复用 ID 会冲突。

局部导航，支持精确接续

进入点、曲线段身份与弧长 station 帮助分段后核对剩余路线。前沿 branch ID 用于归组；下一步执行仍使用最新 path_id。道路可交接区间不表示车位匹配分。

七路相机，按需采集

Model 3 前风挡中央两路、B 柱两路、前翼子板两路与车尾一路，均为 1920 × 1080。中央两路间隔 12 cm、FOV 90°，其余 140°；1 Hz 为传感器采样时钟，不代表移动中的视频流。

终态结果，保存后再确认

交接须满足可见、入口通道和停稳至少 1 秒等条件。最终提交结束本题，错误选择也会结束。CARLA actor 立即释放；回执、结果和历史图片最多保留 120 秒，保存后调用 acknowledge()。

完整字段与约束见 公共协议 ↗ 和 客户端指南 ↗（需仓库访问权限）。业务动作计数 action_seq 与实际仿真帧 sim_frame 分开；回执 completed 不等于任务成功。

04 / OBSERVER & REPLAY

独立观察，保留真实运行记录。

观察通道默认关闭，只读且使用独立凭证。
本次交付提供 API，未附观察页面。

实时观察

启动任务时增加 --observer-port 8766，启用独立进程和本机端口。提供场景、状态、事件、公开导航、实际采集快照及终态公开结果；不提供答案、逐车位分数或参考路线。

离线回放

使用 livat-bench replay <run_folder>/public --api-port 8766 读取保存的记录。回放不连接 CARLA、不重新评分；未完成的运行保持未完成状态。

观察通道供人工使用，不能成为 harness 的额外输入；凭证与 harness token 不通用。记录、图片及 token 留在评测端。观察与回放说明 ↗（需仓库访问权限）

EVALUATION / SCOPE

评测的是完整系统。

系统负责视觉理解、规划、记忆与选择；评测器负责环境、运动合同和计分。本站未发布模型成绩。离线参考回放、使用私有路线的 controller fixture 与模型正式评测分别记录。

v1.2.0 的 146 项单元测试、44 题 / 88 条参考验证通过；在线接口、相机与控制器验收属于运行验证，不是模型自主任务成绩。

完整来源审计未通过。冻结记录中的相邻 harness 来源文件已变化或移除，交付保留这一溯源限制。普通验证通过不能替代完整来源审计；历史性能与图像证据保留各自原构建身份。
