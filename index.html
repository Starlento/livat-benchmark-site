03 / HTTP INTERFACE

通过接口，让系统作出选择。

harness 在自己的进程中运行。
所有请求携带本题 Bearer token。

请求能力
GET /metadata读取全部六路相机、内外参、车辆几何与运动约束
GET /state查询当前生命周期、执行请求、sim_frame、action_seq 和预算
GET /observation读取同帧 RGB 引用、局部占用、车位几何、几何规则与认证路径
GET /local-slots读取当前或历史观测的匿名车位几何与占用证据；只读，不推进仿真
GET /snapshot?observation_id=…一次下载固定观测、清单和对应同帧 PNG；省略 ID 取最新
GET /images/…读取已发布的原始 RGB；历史图片在本题 HTTP 服务期内可读
GET /requests/<request_id>查询动作回执，超时或断线后恢复同一个请求
GET /result读取固定终态公开结果，重复读取不重新评分
POST /move沿当前 path_id 执行自选弧长 distance_m，返回动作回执
POST /wait原地等待 1–10 秒，回执引用完成后的观测
POST /cameras选择相机子集或全部关闭；设备描述始终完整
POST /costs报告累计模型请求与 token 成本
POST /submit停车题以当前车体坐标四角或实际车位号提交；出口题到达区域后自动结束
POST /abandon主动结束当前题，记零分有效尝试；不是基础设施错误，不获得免费重试
POST /acknowledge保存终态结果后显式确认，提前关闭 HTTP 服务

观察后，使用新的路径能力

每次新观测生成新的路径能力和单观测车位 ID；历史快照仍可读取。几何提交引用当前观测的车体坐标。移动距离至少 0.2 米，且不超过当前路径上限；前进或倒车由路径方向决定。

沿途观察，需要主动分段

一次移动只生成终点观测，不提供沿途图像。每段完成后用 snapshot(receipt.output_observation_id) 获取观测和图片，再用新路径决策。预算中断或出口自动完成时需核对实际距离与结果，避免把旧观测当作终点图。

恢复执行，保留原请求身份

move、wait、cameras、costs、submit、abandon 均携带 request_id。超时后用 receipt() 或 wait_for() 查询；相同 ID 与内容不会重复执行，不同内容复用 ID 会冲突。

局部导航，支持精确接续

进入点、曲线段身份与弧长 station 帮助分段后核对剩余路线。前沿 branch ID 用于归组；下一步执行仍使用最新 path_id。termination_reasons 说明当前认证限制，不提供隐藏道路；道路区间不表示车位匹配分或额外交接限制。

六路相机，按需采集

Model 3 前风挡正中央一路 2560 × 1440、FOV 90°；B 柱两路、前翼子板两路及车尾一路均为 1920 × 1080、FOV 140°。1 Hz 为传感器采样时钟，不代表移动中的视频流。

两种终点，保存结果后确认

停车题提交当前车体坐标几何或实际号码；满足 10 米内或同一道路任一空间条件，无需当前可见或停稳 1 秒。尺寸、占用、目标匹配与安全检查继续生效。出口题到达区域即结束，无需选位或停稳；读取 result() 保存终态评分。回执、结果和历史图片最多保留 120 秒，保存后调用 acknowledge()。

完整字段与约束见 公共协议 ↗ 和 客户端指南 ↗（需仓库访问权限）。业务动作计数 action_seq 与实际仿真帧 sim_frame 分开；回执 completed 不等于任务成功。

04 / OBSERVER & REPLAY

独立观察，保留真实运行记录。

观察通道默认关闭，只读且使用独立凭证。
提供统一地图 API，WebUI 可据此渲染。

实时观察

启动单题或 campaign-next 时增加 --observer-port 8766，启用独立进程和本机端口。提供场景、状态、事件、公开导航、实际采集快照及终态公开结果；不提供答案、逐车位分数或参考路线。

无模拟器的静态地图

livat-bench observer --api-port 8767 只提供统一的 GET /scene，无需 CARLA 或任务记录。建筑多边形保留部件与孔洞，充电／无障碍／微型标记独立，可重叠。

离线回放

使用 livat-bench replay <run_folder>/public --api-port 8766 读取保存的记录。回放不连接 CARLA、不重新评分；未完成的运行保持未完成状态。

harness 项目的 WebUI 可用地图向人类展示；模型、策略和执行客户端禁止调用或使用，禁止回流到输入、记忆、缓存或工具结果。展示通道的端口与凭证独立。建筑语义边界不是物理墙，设施／固定占用不是任务准入，地图出入口不是成功区域或可通行性证明。记录、图片及 token 留在评测端。观察与回放说明 ↗（需仓库访问权限）

EVALUATION / SCOPE

评测的是完整系统。

系统负责视觉理解、规划、记忆与选择；评测器负责环境、运动合同和计分。本站未发布模型成绩。离线参考回放、使用私有路线的 controller fixture 与模型正式评测分别记录。

停车题按车位匹配、距离、转向计分；出口题只计距离 60% 与转向 40%，不计车位匹配分。四类汇总权重依次为电梯厅 45%、特殊位 15%、购物目标 15%、出口智行 25%。

v1.5.0 的 196 项测试、64 题 / 128 条参考验证、两种提交的真实 HTTP、实车缓存与原路径对照及运动烟测通过。正式安装包另验独立安装、只读资源、标准库客户端和静态观察接口。新 RGB 未作视觉审查，原阶段证据保留构建身份；这些验证不代表模型自主任务成功。

完整来源审计未通过。冻结记录中独立外部 agentic_parking 的 35 个来源文件发生漂移，交付保留这一溯源限制。普通验证通过不能替代完整来源审计；历史性能与图像证据保留各自原构建身份。
