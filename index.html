TERMINAL / PYTHON ≥ 3.10
python -m pip install ./livat_task_benchmark-1.0.0-py3-none-any.whl

livat-bench list-cases
livat-bench validate

livat-bench serve \
  --case-id <case_id> \
  --host 127.0.0.1 --port 2600 \
  --api-port 8765 \
  --output-dir ./bench-output

换行写法适用于 Bash。PowerShell 请合并为单行；将 <case_id> 替换为 list-cases 返回的题目 ID。

03 / HTTP PROTOCOL V3

通过接口，让系统作出选择。

harness 在自己的进程中运行。
所有请求携带本题 Bearer token。

请求能力
GET /observation读取当前观测、局部匿名占用与当前安全导航路径
GET /images/…读取观测提供的原始 RGB 图像地址
POST /move沿当前 path_id 执行自选弧长 distance_m
POST /wait等待 1–10 秒，返回新观测
POST /propose以四个有序角点登记匿名车位候选
POST /costs报告模型请求与 token 成本
POST /submit提交最终选择，结束本题并返回评分

当前能力随观测刷新

移动或等待后，旧路径、候选与图像地址失效。路径范围以内可自由选择距离，最小 0.2 米。

最终提交结束本题

需在候选车位入口附近停稳至少 1 秒。无效或错误选择也结束任务；结果不提供参考答案。

EVALUATION / SCOPE

评测的是完整系统。

系统负责视觉理解、规划、记忆与选择；评测器负责环境、运动合同和计分。本站展示任务说明与接口，未发布模型成绩。离线参考回放、controller fixture 与正式自主评测分别记录。
